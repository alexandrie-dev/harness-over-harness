# Вариант C — «Для обычного человека»

- Идея: светлое окно, где всё сказано словами. Три скруглённые панели (список, разговор, просмотр) лежат на светло-сером фоне без теней; кнопки подписаны («Подробнее», «Открыть», «Закрыть», «Стоп»), значков нет. Один акцент — глубокий бирюзовый `#0B7A75`: выбранный раздел, «Отправить», «Открыть», кнопка по умолчанию в окне защиты.
- Главная находка: шаги работы — это вертикальный список коротких фраз («Читаю отчёт.txt», «Выполняю команду…» → «Готово, команда завершилась без ошибок»); каждый раскрывается словом «Подробнее» до одной-двух строк.
- Окно защиты отделено от чата: тёмная полоса «Окно защиты HoH», янтарная строка «Это окно защиты, а не чат», размытый и затемнённый фон. «Отклонить» — главная кнопка (по умолчанию), «Разрешить один раз» — осторожная, красным по контуру. Янтарный и красный — только для опасных действий, второго акцента в обычных экранах нет.
- Шрифт: Geologica (переменный, оси wght 100–900), взят из `site/assets/fonts/Geologica-cyrillic.woff2` и `Geologica-latin.woff2`, встроен как data: URI. Основной текст 17 px, подписи 14–15 px. Знаки `₽` и `✓` в Geologica нет, они берутся из системного шрифта.
- Макет живой: ответ «печатается» около 1,5 с; шаги раскрываются; панель выезжает (на 1440 открывается сама после ответа, на 900 только по «Открыть»); Markdown итог.md отрисован своим разбором из исходного текста; первый запуск проходит все три шага (проверка модели сама отвечает «Отвечает за 2 с ✓»); у подтверждения идёт отсчёт 5:00, оба решения показывают итог и «Вернуться в чат».
- Адреса экранов: `#main`, `#firstrun` (также `#firstrun-2`, `#firstrun-3`), `#approval`. Ширина меньше 1100: список прячется за кнопку «Разделы», панель просмотра выезжает поверх разговора.
- Снимки: `main-1440.png`, `firstrun-1440.png`, `main-900.png` (плюс `approval-1440.png`). Заданная команда `--window-size=1440,900` в этом Chrome даёт область страницы 1440×813 (остальное — рамка окна). Снимки сняты с окном выше на 87 px и обрезаны до 1440×900, поэтому страница в них занимает ровно 900. Если снять заданной командой без обрезки, внизу будет пустая полоса, а лента чуть прокрутится вниз; вёрстку я проверил и на 813, текст не обрезан.
- Не успел: разделы «Сотрудники», «Задачи», «Результаты», «Расписание», «Настройки» не нарисованы (при нажатии появляется подсказка); нет тёмной темы и мобильной ширины уже 600 px; в первом запуске не проверяется заполнение полей, кроме «Проверить»; ответ на новое сообщение в чате — заготовка.
