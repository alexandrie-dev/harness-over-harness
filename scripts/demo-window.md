# Показ окна HoH: шпаргалка
1. Запуск: `bash scripts/demo-window.sh`. Он печатает адрес модели и папку показа (данные только там). Закрыли окно — показ окончен, mock остановлен.
2. Мастер «Модель»: оставьте «На этом компьютере». В поле «Адрес» замените `http://localhost:8000/v1` на напечатанный адрес `http://127.0.0.1:ПОРТ/v1`. Ключ здесь не нужен. Нажмите «Проверить», затем «Дальше». «Правила»: папку оставьте «Документы/HoH», там уже лежат файлы для показа. Каждое действие мастера (адрес, папка) подтверждается одним отдельным окном защиты: нажмите «Разрешить». Затем «Знакомство» → в чат.
3. Mock не читает ваш текст: он отвечает заготовками строго по очереди. Поэтому пишите эти фразы в этом порядке, по одной:
 1) «Расскажи подробно, что ты умеешь»: ответ идёт по частям. Через 1–2 с нажмите «Стоп», обрезанный текст останется. 2) «Расскажи, что ты умеешь»: дочитайте до конца.
 3) «Прочитай файл notes.txt». 4) «Запиши в файл result.txt слова "привет из QA"». 5) «Запиши файл qa-outside.txt на уровень выше рабочей папки»: будет отказ.
 6) «Покажи, что в папке»: команды выполнятся без окна подтверждения.
 7) «Удали старые файлы old-1.txt и old-2.txt»: появится окно защиты. Раскройте «Подробности», там команда. Нажмите «Отклонить». 8) То же сообщение: «Разрешить один раз», файлы удалены. 9) То же сообщение: окно появится снова.
 10) «Перезапиши report.txt новым содержимым». 11) «Замени draft на final в config.txt». 12) «Покажи, что в папке выше рабочей, с полным доступом»: окна по-русски.
 13)–15) «Серия обычных команд 1», «… 2», «… 3»: 13 команд без единого окна. Слева раздел «Подтверждения» со всеми решениями.
4. Другой текст или лишнее сообщение получит следующую заготовку не по смыслу, и дальше всё сдвинется. После 38-го ответа модель перестанет отвечать. Начать заново: закройте окно и запустите скрипт без аргумента (новая папка).
5. Перезапуск с историей: закройте окно и запустите `bash scripts/demo-window.sh ПАПКА`, где ПАПКА — напечатанная «Папка показа». История на месте, мастера нет. Mock отвечает с начала очереди: первым снова придёт ответ из п.1.
6. Настоящая модель: новый запуск скрипта без аргумента. Сам mock показу не помешает. В мастере выберите «Облачный сервис», «Адрес» — адрес сервиса (например `https://api.deepseek.com/v1`), «API-ключ» — ваш ключ (только в это поле: он уйдёт в хранилище папки показа, в чат и файлы его не пишите). Если модель не выбралась сама, укажите её в «Дополнительно → Название модели». Нажмите «Проверить» и подтвердите в окне защиты.
