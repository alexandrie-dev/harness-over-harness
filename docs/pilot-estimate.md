## Определение «ядро готово» (поправка)
Было: 118 строк в HEAD + бинарник проходит сценарии dsh HOH-08, относящиеся к ядру + окно на этом бинарнике с живым исполнителем.

Поправка — список сценариев фиксируется заранее. Причина: все 242 сценария загружают полный набор плагинов dsh, включая отложенные и skip. По составу ни один не сводится к 118 строкам.

Предлагаю отбор по теме в `conformance/V1-SCENARIOS.tsv` до подключения прогонщика. По названиям в теме первой версии около 110–130 из 242 (session ~100–113 из 192 плюс часть sdk); не проверено. События непереносимых плагинов прогонщик нормализует или исключает. Это решение записывается в отборе.
