# Дизайн HoH

HoH — рабочее окно, в котором человек разговаривает с харнессом, видит его действия и может вмешаться. У специализированного экрана свой первый вопрос, свой контекст и такие же правила чата, как в остальном приложении.

## Каркас

- Боковая панель отвечает за навигацию. В верхней строке видно, где человек находится. Основное действие занимает центральную колонку шириной существующего чата. Задача и результат остаются в этой колонке.
- Начало разговора — короткий заголовок, при необходимости одно предложение и поле ввода. Примеры помогают начать работу и вставляют черновик, который можно изменить. Если разговор уже открыт, первым делом видны история и поле ответа.
- Проект, харнесс, модель и вложения относятся к сообщению. Размещаем частые настройки в панели под полем ввода. Полную форму показываем для самостоятельной задачи вроде настроек проекта или подтверждения доступа.
- Одно выделенное действие в каждом блоке. В чате это отправка, а во время хода доступна остановка. Настройки и переходы используют спокойные кнопки и привычные значки.

## Визуальные правила

- Используем фон, поверхность, рамку, основной и вторичный текст из токенов HoH. Для фокуса используем токен темы. Фирменный знак Alexandrie живёт в навигации. Знаки Codex и Claude стоят рядом с именем выбранного харнесса.
- Основная сетка — 8 px. Типографика приложения даёт три роли для этого экрана — заголовок, текст сообщения и служебная строка. У поля ввода радиус 16 px. У компактных кнопок и переключателей радиус 8 px.
- Цвет сообщает состояние и сопровождается подписью. Общий янтарный для ожидания человека, зелёный для завершения, красный для ошибки, нейтральный для неактивности. Собираем цвета из семантических токенов, чтобы карточка, счётчик и строка чата давали один сигнал.

## Plugin Creator

Пользователь описывает плагин обычным сообщением. Проект и харнесс выбираются возле отправки. Если доступен ровно один вариант, он уже выбран. «Add project» открывает штатный выбор папки. Первая отправка запускает рабочий чат с выбранным харнессом и инструкцией по созданию и тестированию плагина. В первом сообщении виден текст пользователя, а инструкция остаётся контекстом харнесса. Сначала харнесс задаёт по одному вопросу и ждёт подтверждения плана в чате. Затем работают штатные ответы, журнал инструментов, подтверждения и остановка.

| Состояние | Что видит человек |
| --- | --- |
| Старт | Поле сообщения, доступные проект и харнесс, примеры запросов |
| Нет проекта | Заметное действие «Add project», черновик можно писать |
| Харнесс недоступен | Название и причина, выбор другого рабочего харнесса |
| Отправка | Имя запускаемого харнесса и ожидание перехода в чат |
| Ошибка | Причина рядом с полем, сохранённый черновик и возможность повторить |

Перед показом проверяем холодный старт, отсутствие проекта или доступного харнесса, длинное имя проекта, короткое окно, навигацию клавиатурой, ввод через IME и переход после первой отправки. Нажатие Enter отправляет готовое сообщение. Shift+Enter добавляет строку. Сверяем на реальном экране, что выбранный харнесс получил запрос и его ответ появился в открытом чате.
