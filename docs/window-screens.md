# Окна и экраны нынешнего `ui/` (коммит 93a6f994): что должен покрыть новый дизайн
Общее: общие стили `shared/primitives.css`, иконки `shared/icons.tsx`, состояние `ui/src/lib/store.ts`. Верхняя полоса приватности («Данные на этом компьютере» / «Ответы готовятся на другом компьютере» / «Проверяю, где обрабатываются данные…»): `chat/ChatScreen.tsx:68`. Пути ниже — от `ui/src/screens/`.
1. **Главное окно, мастер первого запуска** (`firstrun/FirstRun.tsx`, `firstrun.css`; вход `ui/index.html` → `main.tsx`, отдельно `ui/firstrun.html`). Шаги-«степпер» 1 Модель / 2 Правила / 3 Знакомство.
   - «Подключите модель»: переключатель «На этом компьютере / Облачный сервис», «Адрес», «Дополнительно → Название модели», «API-ключ» (выключен для локальной; «Ключ сохранён…» после ввода), «Проверить» / «Проверяю…», «Дальше».
   - Ошибки шага 1: неверный адрес, нет ключа для облака, «Модель не ответила. Проверьте адрес.», «Не удалось сохранить ключ…», «Неизвестная ошибка.», подсказка «Сначала проверьте подключение».
   - «Правила работы»: доступ в интернет (два варианта), «Папка для работы» (по умолчанию «Документы/HoH», кнопка выбора), «Назад».
   - «Я ваш Помощник.»: три карточки-примера («Следить за ценой», «Прочитать документ», «Новая задача») и «можно и без примера».
2. **Главное окно, чат** (`chat/ChatScreen.tsx`, `chat.css`, разметка ответа `ui/src/lib/markdown.tsx`).
   - Колонки: левая (Помощник со статусом «работает» / «готов к работе» / «нет связи», пункт «Подтверждения», папка внизу), шапка «Помощник» со статусом «отвечает…» / «останавливаю…» и значком папки.
   - Лента: сообщения человека («Не отправлено» при сбое), ответ Помощника (Markdown; растёт по частям, курсор во время потока), строки шагов «Выполняю команду…» → «Команда завершена» с раскрытием («Результат появится здесь.», «Дополнительного содержимого нет.»).
   - Карточка вопроса Помощника: варианты, «Свой ответ» (`chat/QuestionCard.tsx`).
   - Поле ввода: «Отправить» / «Стоп», подсказка Enter / Shift+Enter.
   - Состояния: пусто — «С чего начнём?» с вариантами «Подключаюсь…» / «Напишите, что нужно сделать…» / «Разговор появится после подключения»; сбой связи с кнопкой «Подключиться ещё раз»; «Связь прервалась, восстанавливаю…».
3. **Главное окно, раздел «Подтверждения»** (`chat/ApprovalsScreen.tsx`). Список решений, новые сверху: что, кто просил («Просил Помощник» / «Вы, в настройках»), когда, ответ («Разрешено один раз» / «Отклонено» / «Без ответа»), объяснение и «Подробности» под раскрытием. Состояния: «Загружаю историю…», «Решений пока нет…», «Не удалось загрузить историю решений.»
4. **Отдельное окно защиты** (`approval/ApprovalWindow.tsx`, `approval.css`, вход `ui/approval.html`; образец `design/build-a/approval-1440.png`, `approval-480x640.png`). «Защита HoH / Отдельное окно, не часть чата»: заголовок действия, метка риска (высокий / средний / низкий), блок «Почему это опасно» или «Почему Помощник спрашивает», «Объяснение Помощника» (или «Помощник не объяснил…»), свёрнутые «Подробности» с командой, таймер «Ответьте за 5:00» с полосой, «Отклонить» / «Разрешить один раз».
   - После ответа: «Разрешено один раз» / «Отклонено — Помощник получил отказ…».
   - Ошибки: «Не удалось получить запрос.», «Не удалось передать ответ.».
   - Виды запроса: удаление и перезапись файлов, полный доступ (эскалация), действия мастера (ключ, адрес, папка).
5. Служебная страница `ui/probe.html` (проверка CSS WebKitGTK) — не для людей, дизайн не нужен.
