# Разрешённые сторонние библиотеки

Единственный список crates, которые можно называть в `[workspace.dependencies]` корневого `Cargo.toml`.
Crate добавляется в `Cargo.toml` только вместе со строкой здесь. Исполнитель сам ничего не добавляет: нужна
новая библиотека — вопрос ведущему (`PORTING.md` §2).

Условия для каждой строки: лицензия из набора MIT, Apache-2.0, BSD, ISC, Zlib, Unicode, CC0-1.0 либо общественное
достояние (решение ведущего 2026-11-16: условий они не накладывают); выпуск в 2026 году
либо отдельное обоснование; минимальная версия Rust не выше 1.97.

Версии, даты выпуска, лицензии и минимальная версия Rust сняты 2026-11-16 с `crates.io/api/v1/crates/<имя>`;
состав API — с docs.rs. Проверены только прямые зависимости. Дерево целиком проверяется после первой сборки
(`cargo tree` и средство проверки лицензий, которое выберет ведущий): этим заданием сборка запрещена.

Замечания к строкам:

- `schemars`: features по умолчанию `derive`, `std`; `preserve_order` включает одноимённый признак `serde_json`,
  который у нас уже включён. Для полей `IndexMap` в конфигурации нужна интеграция schemars с `indexmap`
  (в 1.x это необязательная зависимость); её имя сверить на docs.rs при добавлении.
- `futures-util`: без умолчаний, чтобы не собирать `futures-macro`.
- `syn`: имена features версии 3 сверить при добавлении (в 2.x разбор функций требовал `full`).
- `tokio-util`: `CancellationToken` лежит в модуле `sync`, на его странице docs.rs нет пометки о feature.
- `saphyr-parser`: проверены `Parser::new_from_str`, итератор `Result<(Event, Span), ScanError>`,
  `Event::Scalar(значение, стиль, якорь, тег)`, `Tag { handle, suffix }`. Имена методов `Span` и `Marker`
  для строки и столбца не проверялись.

## 5. Этапы 1–2: предложения (не утверждено ведущим)

Ничего из этого раздела в `Cargo.toml` не внесено. Основа: чтение `src/` пакетов образца со статусом не `-` и этапом 0–5
(204 пакета в `MAP.tsv`), без `tests`, `client`, `experimental`. Пути ниже считаются от образца
(`/mnt/toshiba/alexandrie/hoh/refs/deepseek-harness`). Версии, даты, лицензии и минимальный Rust сняты 2026-11-16
с `crates.io/api/v1/crates/<имя>`; API сверен на docs.rs там, где это сказано. Сборка и запуск не выполнялись:
всё, что требует сборки (набор features, поведение на данных), помечено «не проверено».

Пакеты образца в `node_modules` отсутствуют, поэтому исходный код сторонних библиотек (jsdiff, turndown, yaml, commander)
в образце не лежит: где предложено портировать их алгоритм, исходник берёт писатель из публичного репозитория библиотеки по
решению ведущего. Номера версий библиотек образца взяты из `package.json`.

Изменение условий: в этом задании CC0-1.0 входит в разрешённые лицензии. Причина отказа от `notify` в §4 («CC0-1.0 вне набора»)
этим снимается; решение о возврате `notify` — ниже.

В `Cargo.toml` уже есть `rustix` 1.1.6 (2026-10-27, Apache-2.0 WITH LLVM-exception OR Apache-2.0 OR MIT, Rust 1.65) и
`url` 2.5.8 (2026-01-05, MIT OR Apache-2.0, Rust 1.63), а строк о них в §§1–3 нет: их надо добавить в список.

### 5.4 Нужно решение ведущего

1. **HTTP-клиент и TLS.** (а) `reqwest` 0.13.5 с `rustls`/`aws-lc-rs` (C, ISC) — рекомендую; (б) `hyper` + `hyper-util` + `hyper-rustls` вручную; (в) отказаться от C в TLS — вариантов без предварительных версий нет. Без решения нельзя писать `hoh-llm-deepseek`, `hoh-web-*`, `hoh-http-proxy`, `hoh-otel`.
2. **Правка YAML с сохранением комментариев** (`hoh-credentials-local`, `config-editor`). (а) своя правка по позициям `saphyr-parser` и свой вывод скаляров — рекомендую, потому что файл сверяют побайтно; (б) `yaml-edit` 0.3.6 — быстрее, но вывод скаляров не сверен с `yaml`. Общий модуль разбора YAML для `hoh-settings`, `hoh-skill-*`, `hoh-credentials-local` положить в один crate (имя назначает ведущий).
3. **Разбор командной строки.** (а) свой, под тексты Commander — рекомендую (stdout и событие `--json` проверяются); (б) `clap` 4.6.7 с форматтером помощи и отказов поверх.
4. **Diff для журнала** (`hoh-tool-fs`, `hoh-workspace-changes`): (а) порт jsdiff 9 (BSD-3-Clause) в общий crate — рекомендую, поскольку `diffs` лежат в снимках; (б) `similar` 3.2.1 — побайтно не гарантируется. Нужны имя общего crate и исходник jsdiff (в образце его нет).
5. **Windows без `unsafe`.** Safe-обёрток для `GetFileSecurityW`/`SetFileSecurityW`/`ReplaceFileW`, именованного семафора, `Toolhelp32` и ConPTY (кроме `portable-pty`, релиз 2025-02-11) нет. (а) ветки Windows в `hoh-fs-local`, `hoh-session-persistence-jsonl`, `hoh-subprocess-local` записываются в «Не перенесено» со словами «ждёт этапа 5» вместе с `win32-process` (расширить исключение `PORTING.md` §8 на эти три пакета); на этапе 1 для Windows остаётся `std::fs::rename` без сохранения ACL и без межпроцессного замка — это записывается как отличие — рекомендую; (б) завести отдельный crate с `#![allow(unsafe_code)]` для вызовов Win32 — нарушает линт и правило; (в) принять `portable-pty` 0.9.0 с обоснованием «единственная реализация ConPTY».
6. **`notify` 8.2.2 (CC0-1.0)**: разрешён новым условием. Нужен ли он (три пакета, `awaitWriteFinish` и `atomic` всё равно писать самим) или хватит опроса по таймеру. Рекомендую `notify` + свои `awaitWriteFinish` и `atomic`, `usePolling` через `PollWatcher`.
7. **Изображения (`hoh-attachment-local`).** Побайтное совпадение перекодированных JPEG и WebP с libvips недостижимо. (а) `image` + `moxcms` + `kamadak-exif`, перекодирование в WebP через `webp` 0.3.1 (C, релиз 2025-08-29) — рекомендую, но снимки с перекодированием придётся пометить как «не побайтные»; (б) только JPEG и PNG без WebP — меняет поведение для изображений с альфа-каналом; (в) FFI к libvips — нужен `unsafe`. Сначала нужно выяснить, какие снимки `snapshots/**` перекодируют картинку (я не проверял).
8. **Zstandard** (`hoh-session-persistence-jsonl`): (а) `ruzstd` 0.9.1 (чистый Rust) — рекомендую при условии, что проверка на писателе подтвердит контрольную сумму и частичный вывод; (б) `zstd` 0.14.4 (C, BSD-3-Clause). Решение зависит от того, нужны ли побайтно такие же сжатые файлы (в образце тесты этого не требуют).
9. **SQLite**: `rusqlite` с `bundled` (C) — единственный найденный вариант с FTS5; подтвердить, что C допустим. Лицензия самого SQLite (общественное достояние) не входит в список — внести исключение.
10. **PTY и эмулятор терминала** (`hoh-subprocess-local`, `hoh-terminal-bash`): `pty-process` 0.5.4 для Unix и `alacritty_terminal` 0.26.0 для ответов терминала — рекомендую; запасные `vt100` и `portable-pty`.
11. **LibreOffice** (`hoh-office-kit`): в Rust нет аналога, исходник `@deepseek-ai/libreoffice-kit` в образце отсутствует. (а) трейт `Converter` с реализациями «недоступен» и «внешний `soffice`» — рекомендую; (б) отложить пакет.
12. **`rg`** (`hoh-util-ripgrep`): способ доставки двоичного файла (рядом с приложением как `<exe>-rg`) и версия; пока не определены.

14. **Разбор HTML для turndown**: `html5ever` + `markup5ever_rcdom` и свой порт turndown — рекомендую; `scraper` исключён (MPL-2.0 в зависимостях), `htmd` 0.5.6 побайтно не равен.
