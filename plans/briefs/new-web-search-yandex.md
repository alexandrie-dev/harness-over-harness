## Результат

Крейт `crates/hoh-web-search-yandex` (добавить вручную в workspace не нужно: `members = ["crates/*"]`),
реализующий `hoh_web::WebSearchProvider` (`crates/hoh-web/src/types.rs:84`) для Yandex Search API
(Yandex Cloud, веб-поиск, синхронный режим).

- Конструктор принимает настройки: ключ API, folder id, базовый адрес (по умолчанию официальный; переопределяется
  для тестов), регион/язык поиска (по умолчанию русский), тайм-аут. Секрет не попадает в `Debug`, ошибки и логи.
- `available()` — ложь без ключа или folder id; без сети.
- `search()` — запрос, разбор ответа (если API отдаёт XML в base64 — декодировать и разобрать), отображение
  в `WebSearchResult { content: None, sources, truncated }`: url, заголовок, фрагмент; `max_results` уважается
  и `truncated` честно отражает обрезку. HTML-разметку выделения в заголовках/фрагментах снять.
- Ошибки: 401/403 (ключ), 429 (лимит), 5xx, битый ответ, тайм-аут, отмена через `AbortSignal` — различимые
  ошибки в духе `WebError` из hoh-web; без паники.
- Образец устройства поставщика: dsh `/mnt/toshiba/alexandrie/hoh/refs/deepseek-harness/packages/web/web-search-deepseek/src/provider.ts`
  (только форма: регистрация, id, ошибки). HTTP — `reqwest` из workspace, как в `crates/hoh-web-fetch-http`.
  Новые зависимости — только уже объявленные в корневом `Cargo.toml` (`base64` там есть). XML-парсер
  (`quick-xml`), если нужен, — допиши в корневой `[workspace.dependencies]` одной строкой с комментарием и
  сообщи об этом в отчёте.

## Формат API

Сеть в песочнице разрешена **только** для чтения официальной документации Yandex Cloud (Search API: адрес,
заголовок авторизации, тело запроса, формат ответа, коды ошибок). Запросов к самому API не делать.
В `PORT_NOTES.md` крейта: ссылки на страницы документации, на которых основан формат, и пометка
«формат не проверен на живом API — нужен ключ основателя».
