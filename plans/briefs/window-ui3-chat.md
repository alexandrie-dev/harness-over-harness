# ui2: экран чата (пакет 5 из docs/window.md §6) — для вехи «окно-чат»

Решение CEO 18.11 ~23:55 по словам основателя («я хочу не Tui, а вот как t3»): первое, что видит основатель, —
настольное окно в виде T3 Code. Веха «окно-чат»: он открывает окно, пишет Помощнику, тот отвечает через локальную
модель (протокол OpenAI) и на его глазах читает файл, пишет файл и выполняет команду; в ленте видны шаги работы.
Без сотрудников, задач, кнопок и расписания. Сейчас движка ещё нет — окно пишется против заглушки `hoh-window-stub`.

## Результат

Пакет 5 из `docs/window.md` §6 («Чат: лента, поле ввода, Markdown, остановка»), экран 2 из §2, вид по токенам
`ui/src/styles/tokens.css` и §1 (вид и скорость T3 Code). Файлы: `ui/src/screens/chat/*`, `ui/src/lib/markdown.tsx`,
`ui/src/lib/store.ts`, точка входа `ui/src/main.tsx`.

- Лента: сообщения пользователя и Помощника, поток текста по мере прихода, Markdown без исполнения HTML.
- **Шаги работы в ленте** (главное для вехи): чтение файла, запись файла, выполнение команды — по одной строке простыми
  словами («Читаю отчёт.txt», «Записал итог.md», «Выполняю команду…» → итог, код выхода словами), раскрывается
  по щелчку до краткого содержимого. Никакого JSON, путей вне папки пользователя, слов «инструмент», «сессия», «токен»
  (§2 «Чего обычный человек не видит никогда»).
- Строка ввода, «Отправить», «Стоп» (вызывает `session/cancel`); полоска «данные на этом компьютере».
- Только экран чата: без списка сотрудников, задач, кнопок, расписания (места под них не рисовать).

## Против заглушки

`crates/hoh-window-stub` повторяет записанные сессии dsh. Для шагов работы выбери записанную сессию с чтением, записью
и командой (`/mnt/toshiba/alexandrie/hoh/refs/deepseek-harness/snapshots/sdk/*/session.v4.jsonl`; назови выбранную в
отчёте). Если заглушке для этого нужна правка — она в твоём пакете (только `crates/hoh-window-stub`, с тестом).

- Playwright против заглушки (headless Chromium, только headless): поток текста из `text-turn`; шаги чтения/записи/команды
  видны строками; «Стоп» шлёт `session/cancel`; набор вредных Markdown-строк выводится как текст; 5 000 сообщений

  в отчёте, ведущий соберёт в очереди.

## Условия

- Новые npm-пакеты — только через существующую проверку поставки (`scripts/ui-supply-check.sh`); если нужен новый
  прямой пакет — остановись и напиши ведущему (это решение CEO).
- Сборки cargo: `CARGO_TARGET_DIR=/mnt/toshiba/alexandrie/hoh/target-ui2 CARGO_BUILD_JOBS=2`; остановленные регулятором (T/Tl)
  не возобновлять. Ничего не публиковать, сеть не нужна.
- Сдавай по частям: когда лента с шагами работает против заглушки и проверки зелёные — закончи ход отчётом.
- Отчёт по-русски: файлы, проверки и их вывод, снимки, что не проверено.
