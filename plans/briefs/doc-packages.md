# Документ: договор пакета HoH (HOH-27), только текст

Решение CEO 19.11: пакеты-расширения (то, что агент или человек добавляет как инструменты) на четырёх видах — скилл в
Markdown, Rust, Go, TypeScript. Общий договор: отдельный процесс, JSON-RPC по stdio, манифест с хешем и правами, отмена,
права как пересечение пакет/сотрудник/задача/вызов. Исполнитель TypeScript — Node со схемой защиты из
`research/polyglot-node.md`. Сейчас пишется **только документ**; код хоста пакетов — после вехи «окно-чат».

Напиши один файл `docs/packages.md` (по-русски, простыми словами для автора пакета и для разработчика движка). Основа:
`research/polyglot-packages.md` (раздел «Минимум заложить сейчас»), `research/polyglot-node.md`, `docs/window.md` §4–5,
`docs/kernel.md` (статическая композиция; хост пакетов — обычный плагин), `crates/hoh-protocol` (подтверждения с MAC,
привилегированные методы), `crates/hoh-tools` (определение инструмента, схемы входа/выхода), `crates/hoh-skill`.

Содержание:
1. Что такое пакет; четыре вида; что видит человек в окне.
2. Манифест: каждое поле с типом, обязательностью и примером (formatVersion, id, version, digest — что именно хешируется,
   execution {kind: skill|process|node, entry, target?, runtime?}, tools [{name, description, inputSchema, outputSchema}],
   skills, settingsSchema, requestedPermissions — файлы/сеть/запуск программ). Префикс имён инструментов.
3. Протокол пакет ↔ движок: JSON-RPC 2.0 построчно по stdio; initialize (версии, возможности), tools/call, cancel,
   shutdown; обратные host/fs.*, host/http.*, host/process.* — параметры, ответы, ошибки; ограничения размера кадра,
   времени, памяти; stdout только сообщения, stderr — журнал.
4. Права: пересечение, когда спрашивается человек, связь с подтверждением (MAC связывает хеш пакета, блокировку
   зависимостей и права), пересмотр при обновлении, поведение при недоступной песочнице (запуск запрещён).
5. Node: откуда бинарник и как проверяется, зависимости (pnpm, возраст 7 суток, без скриптов, посредник со списком,
   установка без сети), песочница, что в окне. Только из research/polyglot-node.md, без новых решений.
6. Методы окна hoh/package/list|get|install|enable|remove и уведомление package.changed; какие из них привилегированные.
7. Четыре пакета-примера одного инструмента read-note({path})→{text}: файлы каждого.
8. Что откладывается и открытые вопросы.

Условия: не запускать сборки, тесты, установки; не менять других файлов; ничего не публиковать, не коммитить.
Отчёт по-русски: что написано, где решения взяты из исследований, какие вопросы остались. До 2500 слов в документе.
