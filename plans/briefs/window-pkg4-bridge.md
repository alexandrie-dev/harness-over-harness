# Окно, пакет 4: ядро Tauri — движок как дочерний процесс, мост, фильтр методов, окно подтверждения

Веха «окно-чат» (основатель запускает приложение, вводит адрес и ключ модели, пишет Помощнику, видит шаги, подтверждает
опасное). Пакет 4 из `docs/window.md` §6: файлы `apps/hoh-desktop/src/{engine,bridge,approval}.rs` (+ `main.rs`/`lib.rs`
по необходимости), `apps/hoh-desktop/capabilities/*.json`, `apps/hoh-desktop/tauri.conf.json`. Отдельный workspace
(`apps/hoh-desktop` исключён из корневого), свой Cargo.lock.

## Что сделать
1. **Движок — дочерний процесс** (решение CEO: локальный дочерний процесс, протокол не привязан к stdio — сделай
   транспорт заменяемым): запуск бинарника движка (путь из настройки/рядом с приложением; пока движка нет — запуск
   `hoh-window-stub` из `crates/hoh-window-stub`), JSON-RPC кадры по stdio, перезапуск при падении с сообщением в окно,
   завершение при закрытии приложения.
2. **Мост и фильтр**: команды Tauri, которые уже вызывают экраны (адаптеры `ui/src/screens/firstrun/engine.ts`,
   `ui/src/screens/approval/bridge.ts`, чат — `ui/src/lib/store.ts`): `engine_request`, `approval_current`,
   `approval_decide`, выбор папки. Главное окно может вызывать только разрешённый список методов; привилегированные
   (`PRIVILEGED_METHODS` из `crates/hoh-protocol`) — только через подтверждение. Уведомления движка пересылаются в окно.
3. **Окно подтверждения**: отдельное окно Tauri `ui/approval.html` со своей меткой и правами (capabilities); `mac`
   считает ядро ключом, которого JS не видит (`crates/hoh-protocol` approval: каноническая запись, HMAC-SHA256, срок,
   однократность); закрытие окна = `rejected`; главное окно не может вызвать `approval_decide` (проверка по метке окна).
4. Ключ модели при первом запуске уходит движку (метод сохранения ключа добавляет ui1 в hoh-protocol параллельно — если
   его ещё нет, держи вызов за одной функцией и перечисли в отчёте); в JS-окне ключ не хранится.

## Проверки (§6 пакет 4)
Тесты Rust: ответ с неверным `mac` отвергнут; вызов `approval_decide` из главного окна отвергнут; привилегированный метод
без подтверждения не уходит в движок; заглушка проверяет `mac`. Под `xvfb` (только headless, программный Mesa, как делал
ui2 — `docs/ts/webkitgtk-probe.md`) окно подтверждения открывается, закрытие даёт `rejected`.

## Условия
Документы `docs/window.md` не правь (их правит ui1 параллельно; имена команд сверяй с адаптерами экранов). Экранные файлы
`ui/src/**` не трогай. Сборка: `CARGO_TARGET_DIR=/mnt/toshiba/alexandrie/hoh/target-cf1/desktop` (песочница пишет только в target-cf1), `CARGO_BUILD_JOBS=2`,
`--locked --offline` (крейты Tauri уже скачаны ui2; если чего-то нет в кэше — отчёт, не обход). Сборки в T/Tl не
возобновлять. Ничего не устанавливать, не публиковать, не коммитить. Сдавай по частям: когда пункты 1–2 работают с
заглушкой — отчёт «ГОТОВ мост», затем 3–4. Отчёт по-русски.
